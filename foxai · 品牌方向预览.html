foxai · 品牌方向预览

三个标记方向 × 三套配色。每个标记都按 favicon(16px)和 macOS 托盘单色图标的约束设计——纯剪影可辨识,不依赖渐变。挑一个方向,我再落地到代码。

方向 A / B / C

A · Kit(几何狐首)

最具象、最好记。双耳缺口 + 尖下巴的经典折纸狐造型,眼睛与鼻头是真实镂空,所以单色托盘图标依然成立。鼻头那颗圆点呼应原项目「路由节点」的语义。

辨识度最高
B · Prism(棱面狐面)

把狐首压成一个尖锐的多边形:两只耳朵同时是两条分叉的路由线,汇聚到底部的一个点——正好是「一个入口,多个上游」的形状。比 A 更抽象、更硬朗。

最贴合路由语义
C · Trace(字母 f + 终点节点)

最克制的一版。字母 f 本身画成一条路由路径,末端悬着一个独立节点。和现有界面的极简灰阶语言最贴,但「狐」的意象最弱。

最百搭

尺寸阶梯 · 128 / 48 / 24 / 16 px

单色剪影 · macOS 托盘图标(系统会强制单色反色)

标记 + 文字组合

放进真实导航栏

三套主色(当前界面是纯灰阶,只加这一个强调色就足够拉开层次)

Ember · 狐橙

最直给的「狐」联想,活力强。风险是开发者工具里橙色已经很多。

Amber · 琥珀金

更暖更柔,和灰阶底子最协调,长时间看不刺眼。个性稍弱。

#C77A00 亮#F0A93B 暗
Rust · 赤陶

最沉稳、最「贵」的一版,偏品牌感而非工具感。在暗色下表现最好。

#A8431E 亮#D9764E 暗

配色可以和标记自由组合。切到暗色模式看一眼——三套主色在暗背景下都做了提亮,保证正文对比度过 WCAG AA。
